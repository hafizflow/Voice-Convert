# Hear the Qari — M1: Text and Normalizer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Load the Tanzil Uthmani text into a global word index (surah, ayah, position, stable gid) and provide the Arabic normalizer used identically on Quran text and ASR output.

**Architecture:** `qari/text/` holds a pure `normalize()` function, a Tanzil parser that strips the Basmala prefix, and a `WordIndex` with gid/ayah/surah lookups. Displayed text is always the verbatim Tanzil token; `norm` is a hidden matching key.

**Tech Stack:** Python 3.11 stdlib only (`unicodedata`, `re`, `dataclasses`), pytest.

**Spec:** `docs/superpowers/specs/2026-10-13-hear-the-qari-core-design.md` (milestone M1; licensing section applies to the data file).

## Global Constraints

- Tanzil text is used verbatim only: "CHANGING IT IS NOT ALLOWED". The committed data file must be byte-identical to the download and keep its embedded copyright notice.
- Credit "Tanzil Project" and link to tanzil.net wherever the text is used (data README now, app UI later).
- `Word.uthmani` is the only text ever displayed. `Word.norm` is never shown.
- One normalizer function for both Quran text and ASR output.
- Python 3.11, no new dependencies, tests under `tests/qari/` with unique basenames (the repo has no `tests/__init__.py`).
- Facts measured from the 2026-10-13 download, pinned in tests: 6,236 ayahs, 114 surahs, 77,433 words with Basmala prefixes stripped, sha256 `bf4f57b968d03f4131c070b1e285da9be0e0a108a21c910e872801ca273312c8`.

## Review Focus

- ASR output containing punctuation, digits, Latin, ZWNJ, extra spaces: normalizer must drop them and not glue words (tested: `test_normalize` cases).
- Surahs 95 and 97 spell the Basmala with a shadda; a string-prefix check would leave it in the surah text (tested: fixture includes 95:1 and 97:1).
- Upstream Tanzil file changes format or content: loader must raise `ValueError`, never silently mis-index (tested: gap, missing prefix, empty word; count pinned).
- CRLF line endings or a BOM when the file is re-downloaded on another OS (tested).
- Words that normalize to nothing (marks only) must not enter the index (tested; whole-file assertion).
- Not tested here, owned by M3: ASR that splits a joined Uthmani word (`يا أيها` vs `يَٰٓأَيُّهَا`, 363 verses differ in word count between Uthmani and simple-clean).

```python
"""Arabic normalizer applied identically to Quran text and ASR output.

Lossy by design: the result is only a matching key. Never display it.
"""
import re
import unicodedata

_DROP = (
    set(range(0x0610, 0x061B))      # Quranic annotation signs
    | set(range(0x064B, 0x0660))    # harakat, shadda, sukun, maddah, hamza above/below
    | {0x0640}                      # tatweel
    | set(range(0x06D6, 0x06EE))    # small high/low marks, small waw/yeh, end of ayah
    | set(range(0x08D3, 0x0900))    # extended Arabic marks
    | {0x200B, 0x200C, 0x200D, 0x200E, 0x200F, 0xFEFF}  # zero-width / bidi
)
_FOLD = {
    "أ": "ا", "إ": "ا", "آ": "ا", "ٱ": "ا",
    "ى": "ي", "ی": "ي", "ئ": "ي",
    "ة": "ه", "ؤ": "و", "ک": "ك",
}
_DAGGER = 0x0670


def normalize(text: str) -> str:
    out: list[str] = []
    for ch in unicodedata.normalize("NFKC", text):
        o = ord(ch)
        if o == _DAGGER:
            # Explicit alef in the simple script (مالك, العالمين), except after ي (على, إلى).
            if not (out and out[-1] == "ي"):
                out.append("ا")
            continue
        if o in _DROP:
            continue
        ch = _FOLD.get(ch, ch)
        out.append(ch if "ء" <= ch <= "ي" else " ")
    # Uthmani writes alef-madda as hamza + alef (ءامنوا); the simple script writes آمنوا.
    return " ".join(re.sub("ءا", "ا", "".join(out)).split())


def normalize_words(text: str) -> list[str]:
    return normalize(text).split()
```

`qari/text/index.py`:
```python
from __future__ import annotations

from dataclasses import dataclass
from pathlib import Path

DEFAULT_TANZIL = Path(__file__).resolve().parents[2] / "data" / "tanzil" / "quran-uthmani.txt"


@dataclass(frozen=True)
class Word:
    gid: int        # position in the whole mushaf, 0-based, contiguous
    surah: int
    ayah: int
    pos: int        # 1-based within the ayah
    uthmani: str    # exact Tanzil token, the only text ever displayed
    norm: str       # matching key from normalize(); never displayed


class WordIndex:
    def __init__(self, words: tuple[Word, ...]):
        self.words = words
        self._ayah: dict[tuple[int, int], list[int]] = {}
        self._surah: dict[int, list[int]] = {}
        for w in words:
            a = self._ayah.setdefault((w.surah, w.ayah), [w.gid, w.gid])
            a[1] = w.gid
            s = self._surah.setdefault(w.surah, [w.gid, w.gid])
            s[1] = w.gid
        self._pos = {(w.surah, w.ayah, w.pos): w.gid for w in words}

    @classmethod
    def from_file(cls, path: Path = DEFAULT_TANZIL) -> "WordIndex":
        from qari.text.tanzil import build_words, parse_tanzil
        return cls(build_words(parse_tanzil(Path(path).read_text(encoding="utf-8"))))

    def __len__(self) -> int:
        return len(self.words)

    def __getitem__(self, gid: int) -> Word:
        return self.words[gid]

    def gid(self, surah: int, ayah: int, pos: int) -> int:
        return self._pos[(surah, ayah, pos)]

    def ayah_range(self, surah: int, ayah: int) -> tuple[int, int]:
        first, last = self._ayah[(surah, ayah)]
        return first, last

    def surah_range(self, surah: int) -> tuple[int, int]:
        first, last = self._surah[surah]
        return first, last

    def text(self, start_gid: int, end_gid: int) -> str:
        """Tanzil Uthmani text for the inclusive gid range."""
        return " ".join(w.uthmani for w in self.words[start_gid:end_gid + 1])
```

`qari/text/tanzil.py`:
```python
"""Parse Tanzil's `surah|ayah|text` file and build the global word list.

Tanzil prepends the Basmala to the first ayah of every surah except 1 (where it is
ayah 1) and 9 (which has none). We strip it so surah text is the surah's own words;
the Basmala is represented once, as the four words of 1:1.
"""
from __future__ import annotations

from qari.text.index import Word
from qari.text.normalize import normalize

BASMALA_WORDS = 4
NO_BASMALA_PREFIX = frozenset({1, 9})


def parse_tanzil(text: str) -> list[tuple[int, int, str]]:
    rows = []
    for line in text.splitlines():
        line = line.lstrip("﻿").strip()
        if not line or line.startswith("#"):
            continue
        surah, ayah, body = line.split("|", 2)
        rows.append((int(surah), int(ayah), body.strip()))
    return rows


def build_words(rows: list[tuple[int, int, str]]) -> tuple[Word, ...]:
    basmala_norm: list[str] | None = None
    words: list[Word] = []
    prev_surah, prev_ayah = 0, 0
    for surah, ayah, body in rows:
        if surah == prev_surah:
            if ayah != prev_ayah + 1:
                raise ValueError(f"ayah gap at {surah}:{ayah}")
        elif ayah != 1 or surah < prev_surah:
            raise ValueError(f"bad surah/ayah order at {surah}:{ayah}")
        prev_surah, prev_ayah = surah, ayah

        tokens = body.split()
        if (surah, ayah) == (1, 1):
            basmala_norm = [normalize(t) for t in tokens]
            if len(basmala_norm) != BASMALA_WORDS:
                raise ValueError("1:1 is not the four-word Basmala")
        if ayah == 1 and surah not in NO_BASMALA_PREFIX and surah != 1:
            if basmala_norm is None:
                raise ValueError("1:1 must precede other surahs")
            if [normalize(t) for t in tokens[:BASMALA_WORDS]] != basmala_norm:
                raise ValueError(f"{surah}:1 does not start with the Basmala")
            tokens = tokens[BASMALA_WORDS:]
        for pos, tok in enumerate(tokens, start=1):
            norm = normalize(tok)
            if not norm:
                raise ValueError(f"{surah}:{ayah} word {pos} normalizes to nothing")
            words.append(Word(len(words), surah, ayah, pos, tok, norm))
    return tuple(words)
```
